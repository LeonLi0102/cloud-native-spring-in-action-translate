## 16.3 Knative

Knative 是一个基于 Kubernetes 的平台，提供了一组组件来部署和管理 Serverless 工作负载。

### 16.3.1 Knative 核心组件

* **Serving** — 处理部署和自动扩缩容
* **Eventing** — 处理事件驱动架构
* **Build** — 处理构建和部署

### 16.3.2 安装 Knative

```bash
# 安装 Knative Serving
kubectl apply -f https://github.com/knative/serving/releases/download/knative-v1.9.0/serving-crds.yaml
kubectl apply -f https://github.com/knative/serving/releases/download/knative-v1.9.0/serving-core.yaml

# 安装网络层（Istio）
kubectl apply -f https://github.com/knative/net-istio/releases/download/knative-v1.9.0/net-istio.yaml
```

### 16.3.3 部署服务到 Knative

```yaml
apiVersion: serving.knative.dev/v1
kind: Service
metadata:
  name: catalog-service
spec:
  template:
    spec:
      containers:
        - image: ghcr.io/your-username/catalog-service:latest
          ports:
            - containerPort: 9001
          env:
            - name: SPRING_PROFILES_ACTIVE
              value: production
```

### 16.3.4 自动扩缩容到零

Knative 可以在没有请求时自动将服务缩放为零，节省资源：

```yaml
apiVersion: serving.knative.dev/v1
kind: Service
metadata:
  name: catalog-service
spec:
  template:
    metadata:
      annotations:
        autoscaling.knative.dev/minScale: "0"
        autoscaling.knative.dev/maxScale: "10"
    spec:
      containers:
        - image: ghcr.io/your-username/catalog-service:latest
```

### 16.3.5 流量分割

```yaml
apiVersion: serving.knative.dev/v1
kind: Service
metadata:
  name: catalog-service
spec:
  template:
    spec:
      containers:
        - image: ghcr.io/your-username/catalog-service:v1
  traffic:
    - revisionName: catalog-service-v1
      percent: 90
    - revisionName: catalog-service-v2
      percent: 10
```

Knative 简化了在 Kubernetes 上运行 Serverless 应用程序。
