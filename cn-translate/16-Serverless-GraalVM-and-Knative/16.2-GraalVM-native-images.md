## 16.2 GraalVM 原生镜像

GraalVM 是一个高性能的多语言虚拟机，可以将 Java 应用程序编译为原生镜像，显著减少启动时间和内存占用。

### 16.2.1 理解原生镜像

原生镜像是一个自包含的可执行文件，包含应用程序和所有依赖项，不需要 JVM 即可运行。

优势：
* **快速启动** — 毫秒级启动时间
* **低内存占用** — 更少的内存消耗
* **无需 JVM** — 可以在没有 Java 运行时的环境中运行

### 16.2.2 使用 Spring Boot 构建原生镜像

使用 Gradle：

```bash
./gradlew bootBuildImage --builder=ghcr.io/graalvm/native-image:latest
```

使用 Maven：

```bash
mvn -Pnative spring-boot:build-image
```

### 16.2.3 配置原生镜像

```xml
<build>
    <plugins>
        <plugin>
            <groupId>org.graalvm.buildtools</groupId>
            <artifactId>native-maven-plugin</artifactId>
        </plugin>
        <plugin>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-maven-plugin</artifactId>
            <configuration>
                <image>
                    <builder>paketobuildpacks/builder-jammy-java:latest</builder>
                </image>
            </configuration>
        </plugin>
    </plugins>
</build>
```

### 16.2.4 测试原生镜像

```bash
# 构建原生镜像
./mvnw -Pnative native:compile

# 运行原生镜像
./target/catalog-service
```

GraalVM 原生镜像特别适合 Serverless 和容器化部署。
