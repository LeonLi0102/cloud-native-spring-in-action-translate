## 14.2 Kubernetes Secrets

Secret 是 Kubernetes 中用于存储敏感信息的对象，如密码、令牌和密钥。它比 ConfigMap 更安全，因为数据是 base64 编码的。

### 14.2.1 创建 Secret

```bash
$ kubectl create secret generic db-credentials \
    --from-literal=username=user \
    --from-literal=password=password
```

或使用 YAML：

```yaml
apiVersion: v1
kind: Secret
metadata:
  name: db-credentials
type: Opaque
data:
  username: dXNlcg==  # base64 编码的 "user"
  password: cGFzc3dvcmQ=  # base64 编码的 "password"
```

### 14.2.2 在 Pod 中使用 Secret

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: catalog-service
spec:
  containers:
    - name: catalog-service
      image: catalog-service:latest
      env:
        - name: DB_USERNAME
          valueFrom:
            secretKeyRef:
              name: db-credentials
              key: username
        - name: DB_PASSWORD
          valueFrom:
            secretKeyRef:
              name: db-credentials
              key: password
```

### 14.2.3 挂载 Secret 为文件

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: catalog-service
spec:
  containers:
    - name: catalog-service
      image: catalog-service:latest
      volumeMounts:
        - name: secret-volume
          mountPath: /etc/secrets
          readOnly: true
  volumes:
    - name: secret-volume
      secret:
        secretName: db-credentials
```

### 14.2.4 使用 External Secrets Operator

对于更安全的密钥管理，可以使用 External Secrets Operator 从外部密钥管理服务（如 AWS Secrets Manager、HashiCorp Vault）同步密钥。

Secrets 提供了比 ConfigMap 更安全的敏感数据存储方式。
