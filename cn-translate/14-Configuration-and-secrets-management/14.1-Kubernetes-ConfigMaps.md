## 14.1 Kubernetes ConfigMaps

ConfigMap 是 Kubernetes 中用于存储非机密配置数据的对象。它允许您将配置与容器镜像分离，使应用程序更具可移植性。

### 14.1.1 创建 ConfigMap

```yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: catalog-service-config
data:
  application.yml: |
    spring:
      datasource:
        url: jdbc:postgresql://polar-postgres:5432/polardb_catalog
        username: user
        password: password
    server:
      port: 9001
```

### 14.1.2 在 Pod 中使用 ConfigMap

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: catalog-service
spec:
  containers:
    - name: catalog-service
      image: catalog-service:latest
      envFrom:
        - configMapRef:
            name: catalog-service-config
```

### 14.1.3 挂载 ConfigMap 为文件

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: catalog-service
spec:
  containers:
    - name: catalog-service
      image: catalog-service:latest
      volumeMounts:
        - name: config-volume
          mountPath: /config
  volumes:
    - name: config-volume
      configMap:
        name: catalog-service-config
```

### 14.1.4 更新 ConfigMap

```bash
$ kubectl create configmap catalog-service-config \
    --from-file=application.yml \
    --dry-run=client -o yaml | kubectl apply -f -
```

ConfigMap 使配置管理更加灵活和可维护。
