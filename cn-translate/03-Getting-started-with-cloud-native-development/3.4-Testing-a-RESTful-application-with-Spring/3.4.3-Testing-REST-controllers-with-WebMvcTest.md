### 3.4.3 使用 @WebMvcTest 测试 REST 控制器

一些集成测试可能不需要完全初始化的应用上下文。例如，当您测试数据持久化层时，不需要加载 Web 组件。如果您正在测试 Web 组件，则不需要加载数据持久化层。

Spring Boot 允许您使用仅用一组组件（Bean）初始化的上下文，针对特定的应用切片。切片测试不使用 `@SpringBootTest` 注解，而是使用一组专用于应用特定部分的注解之一：Web MVC、Web Flux、REST 客户端、JDBC、JPA、Mongo、Redis、JSON 等。这些注解中的每一个都会初始化一个应用上下文，过滤掉该切片之外的所有 Bean。

我们可以通过使用 `@WebMvcTest` 注解来测试 Spring MVC 控制器是否按预期工作。该注解会在模拟 Web 环境（无运行中服务器）中加载 Spring 应用上下文，配置 Spring MVC 基础设施，并仅包含 MVC 层使用的 Bean，如 `@RestController` 和 `@RestControllerAdvice`。将上下文限制为被测特定控制器使用的 Bean 也是一个好主意。我们可以通过在新的 `BookControllerMvcTests` 类中将控制器类作为 `@WebMvcTest` 注解的参数来实现。

**代码清单 3.18 Web MVC 切片的集成测试**

```java
package com.polarbookshop.catalogservice.web;

import com.polarbookshop.catalogservice.domain.BookNotFoundException;
import com.polarbookshop.catalogservice.domain.BookService;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.autoconfigure.web.servlet.WebMvcTest;
import org.springframework.boot.test.mock.mockito.MockBean;
import org.springframework.test.web.servlet.MockMvc;
import static org.mockito.BDDMockito.given;
import static org.springframework.test.web.servlet.request
 .MockMvcRequestBuilders.get;
import static org.springframework.test.web.servlet.result
 .MockMvcResultMatchers.status;

@WebMvcTest(BookController.class)
// 标识一个专注于 Spring MVC 组件的测试类，明确指定 BookController
class BookControllerMvcTests {
 @Autowired
 private MockMvc mockMvc; // 在模拟环境中测试 Web 层的工具类

 @MockBean
 private BookService bookService; // 将 BookService 的模拟添加到 Spring 应用上下文

 @Test
 void whenGetBookNotExistingThenShouldReturn404() throws Exception {
 String isbn = "73737313940";

 // 定义 BookService 模拟 Bean 的预期行为
 given(bookService.viewBookDetails(isbn))
 .willThrow(BookNotFoundException.class);

 // 使用 MockMvc 执行 HTTP GET 请求并验证结果
 mockMvc
 .perform(get("/books/" + isbn))
 .andExpect(status().isNotFound()); // 预期响应为 "404 Not Found" 状态
 }
}
```

> **警告** 如果您使用 IntelliJ IDEA，可能会收到 `MockMvc` 无法自动装配的警告。不用担心。这是一个误报。您可以通过在字段上添加 `@SuppressWarnings("SpringJavaInjectionPointsAutowiringInspection")` 注解来消除该警告。

然后您可以使用以下命令运行测试：

```bash
$ ./gradlew test --tests BookControllerMvcTests
```

`MockMvc` 是一个工具类，允许您在不加载 Tomcat 等服务器的情况下测试 Web 端点。这种测试自然比我们在上一节中编写的测试更轻量，后者的测试需要内嵌服务器才能运行。

切片测试针对仅包含该应用切片所需配置部分的应用上下文运行。对于切片之外的协作 Bean（如 `BookService` 类），我们使用模拟。

使用 `@MockBean` 注解创建的模拟与标准模拟（例如使用 Mockito 创建的模拟）不同，因为该类不仅被模拟，而且模拟还被包含在应用上下文中。每当上下文被要求自动装配该 Bean 时，它会自动注入模拟而不是实际实现。
