### 3.4.4 使用 @JsonTest 测试 JSON 序列化

`BookController` 中方法返回的 `Book` 对象被解析为 JSON 对象。默认情况下，Spring Boot 自动配置 Jackson 库来将 Java 对象解析为 JSON（序列化）以及反向操作（反序列化）。

使用 `@JsonTest` 注解，您可以测试领域对象的 JSON 序列化和反序列化。`@JsonTest` 加载 Spring 应用上下文并自动配置正在使用的特定库的 JSON 映射器（默认为 Jackson）。此外，它还配置了 `JacksonTester` 工具，您可以使用它来检查 JSON 映射是否按预期工作，该工具依赖 JsonPath 和 JSONAssert 库。

> **注意** JsonPath 提供了可用于导航 JSON 对象并从中提取数据的表达式。例如，如果我想从 `Book` 对象的 JSON 表示中获取 `isbn` 字段，我可以使用以下 JsonPath 表达式：`@.isbn`。有关 JsonPath 库的更多信息，请参阅项目文档：[https://github.com/json-path/JsonPath](https://github.com/json-path/JsonPath)。

以下代码清单展示了在新的 `BookJsonTests` 类中实现的序列化和反序列化测试示例。

**代码清单 3.19 JSON 切片的集成测试**

```java
package com.polarbookshop.catalogservice.web;

import com.polarbookshop.catalogservice.domain.Book;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.autoconfigure.json.JsonTest;
import org.springframework.boot.test.json.JacksonTester;
import static org.assertj.core.api.Assertions.assertThat;

@JsonTest // 标识一个专注于 JSON 序列化的测试类
class BookJsonTests {
 @Autowired
 private JacksonTester<Book> json; // 用于断言 JSON 序列化和反序列化的工具类

 @Test
 void testSerialize() throws Exception {
 var book = new Book("1234567890", "Title", "Author", 9.90);
 var jsonContent = json.write(book);
 // 验证从 Java 到 JSON 的解析，使用 JsonPath 格式导航 JSON 对象
 assertThat(jsonContent).extractingJsonPathStringValue("@.isbn")
 .isEqualTo(book.isbn());
 assertThat(jsonContent).extractingJsonPathStringValue("@.title")
 .isEqualTo(book.title());
 assertThat(jsonContent).extractingJsonPathStringValue("@.author")
 .isEqualTo(book.author());
 assertThat(jsonContent).extractingJsonPathNumberValue("@.price")
 .isEqualTo(book.price());
 }

 @Test
 void testDeserialize() throws Exception {
 // 使用 Java 文本块功能定义 JSON 对象
 var content = """
 {
 "isbn": "1234567890",
 "title": "Title",
 "author": "Author",
 "price": 9.90
 }
 """;
 // 验证从 JSON 到 Java 的解析
 assertThat(json.parse(content))
 .usingRecursiveComparison()
 .isEqualTo(new Book("1234567890", "Title", "Author", 9.90));
 }
}
```

> **警告** 如果您使用 IntelliJ IDEA，可能会收到 `JacksonTester` 无法自动装配的警告。不用担心。这是一个误报。您可以通过在字段上添加 `@SuppressWarnings("SpringJavaInjectionPointsAutowiringInspection")` 注解来消除该警告。

您可以使用以下命令运行测试：

```bash
$ ./gradlew test --tests BookJsonTests
```
