### 6.2.2 使用 Dockerfile 容器化 Spring Boot

云原生应用程序是自包含的。Spring Boot 允许您将应用程序打包为独立的 JAR，包含运行所需的一切（运行时环境除外）。这使得容器化非常直接，因为除了 JAR 工件之外，容器镜像中只需要操作系统和 JRE。

首先，您需要确定要基于哪个镜像。您可以选择 Ubuntu 镜像，然后显式安装 JRE，或者选择已经提供 JRE 的基础镜像，这样更方便。所有主要的 OpenJDK 发行版都有相关的镜像在 Docker Hub 上可用。在本例中，我将使用 Eclipse Temurin 17。

打开您的 Catalog Service 项目，在根文件夹中创建一个名为 Dockerfile 的空文件（无扩展名）。

**代码清单 6.2 描述 Catalog Service 镜像的 Dockerfile**

```dockerfile
FROM eclipse-temurin:17

WORKDIR workspace

ARG JAR_FILE=build/libs/*.jar
COPY ${JAR_FILE} catalog-service.jar

ENTRYPOINT ["java", "-jar", "catalog-service.jar"]
```

在继续之前，您需要为 Catalog Service 应用程序构建 JAR 工件。打开终端窗口，导航到 Catalog Service 项目的根文件夹：

```bash
$ ./gradlew clean bootJar
```

然后构建容器镜像：

```bash
$ docker build -t catalog-service .
```

让我们验证它是否工作。添加两个参数到 docker run 命令：

```bash
$ docker run -d \
    --name catalog-service \
    --net catalog-network \
    -p 9001:9001 \
    -e SPRING_DATASOURCE_URL=jdbc:postgresql://polar-postgres:5432/polardb_catalog \
    -e SPRING_PROFILES_ACTIVE=testdata \
    catalog-service
```

打开终端窗口，调用应用程序并验证其是否正常工作：

```bash
$ http :9001/books
```

完成后，记得删除两个容器：

```bash
$ docker rm -f catalog-service polar-postgres
```
