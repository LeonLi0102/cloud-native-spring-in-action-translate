### 6.2.4 使用 Cloud Native Buildpacks 容器化 Spring Boot

Cloud Native Buildpacks 是一种将应用程序转换为容器镜像的标准方式，无需编写 Dockerfile。Buildpacks 会自动检测应用程序类型并相应地构建镜像。

Spring Boot 通过 spring-boot-maven-plugin 和 spring-boot-gradle-plugin 提供了对 Buildpacks 的内置支持。

#### 使用 Gradle

```bash
$ ./gradlew bootBuildImage
```

#### 使用 Maven

```bash
$ mvn spring-boot:build-image
```

这些命令将自动：

1. 检测应用程序类型（Spring Boot）
2. 选择合适的基础镜像
3. 配置运行时环境
4. 构建优化的容器镜像

Buildpacks 的优势：

* **无需编写 Dockerfile** — 自动检测和配置
* **最佳实践** — 自动应用安全和性能最佳实践
* **可重复性** — 在任何环境中产生相同的镜像
* **安全性** — 自动修补基础镜像漏洞

构建完成后，您可以使用 docker run 命令运行应用程序：

```bash
$ docker run -d \
    --name catalog-service \
    --net catalog-network \
    -p 9001:9001 \
    -e SPRING_DATASOURCE_URL=jdbc:postgresql://polar-postgres:5432/polardb_catalog \
    -e SPRING_PROFILES_ACTIVE=testdata \
    catalog-service:0.0.1-SNAPSHOT
```
