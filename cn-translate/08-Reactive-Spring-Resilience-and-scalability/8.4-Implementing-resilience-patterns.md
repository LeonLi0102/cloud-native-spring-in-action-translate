## 8.4 实现弹性模式

在分布式系统中，服务之间的调用可能失败。为了构建有韧性的应用程序，我们需要实现各种弹性模式。

### 8.4.1 使用 Resilience4j

Resilience4j 是一个轻量级容错库，提供以下模式：

* **重试（Retry）** — 自动重试失败的操作
* **断路器（Circuit Breaker）** — 当失败率超过阈值时停止调用
* **限流（Rate Limiter）** — 限制请求速率
* **隔离（Bulkhead）** — 隔离依赖项以防止级联故障

### 8.4.2 实现重试

```java
@Service
public class CatalogClient {
    
    private final WebClient webClient;
    
    public Mono<Book> getBookByIsbn(String isbn) {
        return webClient.get()
            .uri("/books/{isbn}", isbn)
            .retrieve()
            .bodyToMono(Book.class)
            .retry(3);
    }
}
```

### 8.4.3 实现断路器

```java
@Service
public class CatalogClient {
    
    public Mono<Book> getBookByIsbn(String isbn) {
        return webClient.get()
            .uri("/books/{isbn}", isbn)
            .retrieve()
            .bodyToMono(Book.class)
            .transformDeferred(CircuitBreakerOperator.of("catalogService"));
    }
}
```

### 8.4.4 实现超时

```java
@Service
public class CatalogClient {
    
    public Mono<Book> getBookByIsbn(String isbn) {
        return webClient.get()
            .uri("/books/{isbn}", isbn)
            .retrieve()
            .bodyToMono(Book.class)
            .timeout(Duration.ofSeconds(3));
    }
}
```
