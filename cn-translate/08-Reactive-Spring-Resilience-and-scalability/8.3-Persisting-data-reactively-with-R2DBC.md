## 8.3 使用 R2DBC 进行响应式数据持久化

Spring Data R2DBC 提供了响应式方式访问关系型数据库的能力，基于 Reactive Relational Database Connectivity (R2DBC) 规范。

### 8.3.1 使用 Spring Data R2DBC

首先添加依赖：

```groovy
dependencies {
    implementation 'org.springframework.boot:spring-boot-starter-data-r2dbc'
    runtimeOnly 'io.r2dbc:r2dbc-postgresql'
}
```

配置 R2DBC：

```yaml
spring:
  r2dbc:
    url: r2dbc:postgresql://localhost:5432/polardb_catalog
    username: user
    password: password
```

### 8.3.2 定义响应式仓库

```java
public interface OrderRepository extends ReactiveCrudRepository<Order, Long> {
    Flux<Order> findByCustomerEmail(String email);
}
```

### 8.3.3 使用响应式事务

```java
@Service
public class OrderService {
    
    private final OrderRepository orderRepository;
    private final BookClient bookClient;
    
    @Transactional
    public Mono<Order> createOrder(Order order) {
        return bookClient.getBookByIsbn(order.getIsbn())
            .flatMap(book -> {
                order.setBookTitle(book.getTitle());
                order.setBookPrice(book.getPrice());
                return orderRepository.save(order);
            });
    }
}
```
