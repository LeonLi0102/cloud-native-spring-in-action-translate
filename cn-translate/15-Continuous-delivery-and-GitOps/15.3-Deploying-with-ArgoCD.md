## 15.3 使用 Argo CD 部署

Argo CD 提供了多种部署策略，包括蓝绿部署、金丝雀发布和渐进式交付。

### 15.3.1 安装 Argo CD

```bash
kubectl create namespace argocd
kubectl apply -n argocd -f https://raw.githubusercontent.com/argoproj/argo-cd/stable/manifests/install.yaml
```

### 15.3.2 访问 Argo CD UI

```bash
kubectl port-forward svc/argocd-server -n argocd 8080:443
```

### 15.3.3 创建应用程序

```bash
argocd app create catalog-service \
    --repo https://github.com/your-username/k8s-config.git \
    --path catalog-service \
    --dest-server https://kubernetes.default.svc \
    --dest-namespace polar-bookshop \
    --sync-policy automated
```

### 15.3.4 同步应用程序

```bash
argocd app sync catalog-service
```

### 15.3.5 回滚部署

```bash
argocd app rollback catalog-service 1
```

Argo CD 简化了 Kubernetes 应用程序的部署和管理。
