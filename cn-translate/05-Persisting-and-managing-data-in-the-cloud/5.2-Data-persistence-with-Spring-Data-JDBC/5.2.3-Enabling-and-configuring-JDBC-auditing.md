### 5.2.3 启用和配置 JDBC 审计

在持久化数据时，了解表中每行的创建日期和最后更新日期很有用。在通过身份验证和授权保护应用程序后，您甚至可以注册谁创建了每个实体以及最近更新了它。所有这些都称为数据库审计。

使用 Spring Data JDBC，您可以在配置类上使用 @EnableJdbcAuditing 注解为所有持久化实体启用审计。在 com.polarbookshop.catalogservice.config 包中，添加一个 DataConfig 类来收集 JDBC 相关配置。

**代码清单 5.9 通过注解配置启用 JDBC 审计**

```java
package com.polarbookshop.catalogservice.config;

import org.springframework.context.annotation.Configuration;
import org.springframework.data.jdbc.repository.config.EnableJdbcAuditing;

@Configuration
@EnableJdbcAuditing
public class DataConfig {}
```

> 注意：在 Spring Data JPA 中，您需要使用 @EnableJpaAuditing 注解启用 JPA 审计，并使用 @EntityListeners(AuditingEntityListener.class) 注解实体类使其监听审计事件，这不会像 Spring Data JDBC 那样自动发生。

启用此功能后，每当创建、更新或删除数据时都会生成审计事件。Spring Data 提供了方便的注解（如表 5.1 所列），我们可以在专用字段上使用它们来捕获此类事件的信息（审计元数据）并将其作为实体的一部分存储在数据库中。

**表 5.1 启用数据库审计后，可以在实体字段上使用这些注解来捕获审计元数据**

| 注解 | 在实体字段上的作用 |
|------|-------------------|
| @CreatedBy | 标识表示创建实体的用户的字段。在创建时定义，永不更改。 |
| @CreatedDate | 标识表示实体创建时间的字段。在创建时定义，永不更改。 |
| @LastModifiedBy | 标识表示最近修改实体的用户的字段。在每次创建或更新操作时更新。 |
| @LastModifiedDate | 标识表示实体最近修改时间的字段。在每次创建或更新操作时更新。 |

在 Catalog Service 中，我们可以向 Book 记录添加 createdDate 和 lastModifiedDate 字段。在第 12 章介绍 Spring Security 后，我们将扩展此对象以捕获谁创建或更新了实体。

打开 Book 记录，添加两个新字段，并相应地更新静态工厂方法。在实例化新对象时它们可以为 null，因为它们将由 Spring Data 在底层填充。

**代码清单 5.10 添加字段以在持久化实体中存储审计元数据**

```java
package com.polarbookshop.catalogservice.domain;

public record Book (
 @Id Long id,
 ...
 @CreatedDate Instant createdDate,
 @LastModifiedDate Instant lastModifiedDate,
 @Version int version
) {
 public static Book of(
 String isbn,
 String title,
 String author,
 Double price
 ) {
 return new Book(null, isbn, title, author, price, null, null, 0);
 }
}
```

扩展 Book 记录后，BookService 类需要再次更新。打开它并更改 editBookDetails() 方法，确保在调用数据层时正确传递审计元数据。

**代码清单 5.11 更新图书时包含现有审计元数据**

```java
package com.polarbookshop.catalogservice.domain;

@Service
public class BookService {
 ...
 public Book editBookDetails(String isbn, Book book) {
 return bookRepository.findByIsbn(isbn)
 .map(existingBook -> {
 var bookToUpdate = new Book(
 existingBook.id(),
 existingBook.isbn(),
 book.title(),
 book.author(),
 book.price(),
 existingBook.createdDate(),
 existingBook.lastModifiedDate(),
 existingBook.version()
 );
 return bookRepository.save(bookToUpdate);
 })
 .orElseGet(() -> addBookToCatalog(book));
 }
}
```

接下来，让我们更新 schema.sql 文件，为 book 表添加新字段的列。

**代码清单 5.12 为 book 表添加审计元数据列**

```sql
DROP TABLE IF EXISTS book;

CREATE TABLE book (
 id BIGSERIAL PRIMARY KEY NOT NULL,
 author varchar(255) NOT NULL,
 isbn varchar(255) UNIQUE NOT NULL,
 price float8 NOT NULL,
 title varchar(255) NOT NULL,
 version integer NOT NULL,
 created_date timestamp NOT NULL,
 last_modified_date timestamp NOT NULL
);
```
