## 10.2 Spring Cloud Function

Spring Cloud Function 是一个 Spring 项目，它允许您以函数式风格编写业务逻辑，并将其部署到各种平台。

### 10.2.1 理解函数式编程

函数式编程是一种声明式编程范式，它将计算视为数学函数的求值，并避免改变状态和可变数据。

Spring Cloud Function 提供了三种核心抽象：

* **Function<I, O>** — 接受输入并产生输出
* **Consumer<I>** — 接受输入但不产生输出
* **Supplier<O>** — 不接受输入但产生输出

### 10.2.2 定义函数

```java
@Configuration
public class FunctionConfig {
    
    @Bean
    public Function<Order, OrderAcceptedMessage> orderAccepted() {
        return order -> {
            // 处理订单逻辑
            return new OrderAcceptedMessage(order.getId());
        };
    }
    
    @Bean
    public Consumer<OrderAcceptedMessage> orderAcceptedConsumer() {
        return message -> {
            // 消费订单接受消息
            System.out.println("Order accepted: " + message.getOrderId());
        };
    }
}
```

### 10.2.3 测试函数

```java
@SpringBootTest
class FunctionTests {
    
    @Autowired
    private FunctionCatalog catalog;
    
    @Test
    void shouldProcessOrder() {
        Function<Order, OrderAcceptedMessage> orderAccepted = 
            catalog.lookupFunction("orderAccepted");
        
        Order order = new Order(1L, "1234567890", 2);
        OrderAcceptedMessage result = orderAccepted.apply(order);
        
        assertThat(result.getOrderId()).isEqualTo(1L);
    }
}
```
