## 10.3 Spring Cloud Stream

Spring Cloud Stream 是一个构建事件驱动微服务的框架，它简化了与消息代理的集成。

### 10.3.1 理解 Spring Cloud Stream

Spring Cloud Stream 提供了一种声明式的方式来绑定消息通道，使您可以专注于业务逻辑而不是消息基础设施。

核心概念：

* **Binder** — 与消息代理交互的抽象
* **Channel** — 消息通道的抽象
* **Destination** — 消息代理中的目标（主题或队列）

### 10.3.2 配置 RabbitMQ

```yaml
spring:
  cloud:
    stream:
      rabbit:
        binder:
          hosts: localhost
          port: 5672
          username: guest
          password: guest
      bindings:
        orderAccepted-out-0:
          destination: order-accepted
        orderAcceptedConsumer-in-0:
          destination: order-accepted
```

### 10.3.3 发布事件

```java
@Service
public class OrderService {
    
    private final StreamBridge streamBridge;
    
    public OrderService(StreamBridge streamBridge) {
        this.streamBridge = streamBridge;
    }
    
    public Order acceptOrder(Order order) {
        // 保存订单逻辑
        OrderAcceptedMessage message = new OrderAcceptedMessage(order.getId());
        streamBridge.send("orderAccepted-out-0", message);
        return order;
    }
}
```

### 10.3.4 消费事件

```java
@Service
public class OrderAcceptedConsumer {
    
    @Bean
    public Consumer<OrderAcceptedMessage> orderAcceptedConsumer() {
        return message -> {
            System.out.println("Processing order: " + message.getOrderId());
            // 处理订单逻辑
        };
    }
}
```

### 10.3.5 使用 Spring Cloud Stream 与 Kafka

```yaml
spring:
  cloud:
    stream:
      kafka:
        binder:
          brokers: localhost:9092
      bindings:
        orderAccepted-out-0:
          destination: order-accepted
```

Spring Cloud Stream 使得构建事件驱动应用程序变得简单，无论底层使用 RabbitMQ 还是 Kafka。
