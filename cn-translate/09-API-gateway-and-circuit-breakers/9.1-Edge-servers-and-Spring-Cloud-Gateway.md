## 9.1 边缘服务器和 Spring Cloud Gateway

边缘服务器是系统边缘的应用程序，实现 API 网关和横切关注点等功能。Spring Cloud Gateway 大大简化了构建边缘服务的过程。

### 9.1.1 Spring Cloud Gateway 入门

Spring Cloud Gateway 基于 Spring Boot 和 Spring WebFlux，提供了一种简单的方式来路由到 API。它旨在提供一种简单而有效的方式来路由到 API，并为它们提供横切关注点，例如安全性、监控指标和弹性。

添加依赖：

```groovy
dependencies {
    implementation 'org.springframework.cloud:spring-cloud-starter-gateway'
}
```

### 9.1.2 定义路由和谓词

Spring Cloud Gateway 提供三个主要构建块：

* **路由（Route）** — 由唯一 ID、谓词集合、URI 和过滤器集合标识
* **谓词（Predicate）** — 匹配 HTTP 请求的任何内容，包括路径、主机、头、查询参数、cookie 和主体
* **过滤器（Filter）** — 在转发请求之前或之后修改 HTTP 请求或响应

配置路由示例：

```yaml
spring:
  cloud:
    gateway:
      routes:
        - id: catalog-route
          uri: ${CATALOG_SERVICE_URL:http://localhost:9001}/books
          predicates:
            - Path=/books/**
        - id: order-route
          uri: ${ORDER_SERVICE_URL:http://localhost:9002}/orders
          predicates:
            - Path=/orders/**
```

### 9.1.3 使用过滤器

过滤器可以在请求转发到下游服务之前或之后修改请求。Spring Cloud Gateway 提供了许多内置过滤器：

* **AddRequestHeader** — 添加请求头
* **AddResponseHeader** — 添加响应头
* **RewritePath** — 重写请求路径
* **Retry** — 重试失败的请求
* **CircuitBreaker** — 集成断路器

```yaml
spring:
  cloud:
    gateway:
      routes:
        - id: catalog-route
          uri: http://localhost:9001
          predicates:
            - Path=/books/**
          filters:
            - AddRequestHeader=X-Source, gateway
            - StripPrefix=1
```
