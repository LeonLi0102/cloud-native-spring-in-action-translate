## 9.5 使用 Kubernetes Ingress 管理外部访问

Kubernetes Ingress 提供了从集群外部访问集群内服务的 HTTP 和 HTTPS 路由。

### 9.5.1 配置 Ingress

Ingress 配置示例：

```yaml
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: polar-bookshop-ingress
  annotations:
    nginx.ingress.kubernetes.io/rewrite-target: /
spec:
  rules:
    - host: polar-bookshop.local
      http:
        paths:
          - path: /books
            pathType: Prefix
            backend:
              service:
                name: edge-service
                port:
                  number: 9000
          - path: /orders
            pathType: Prefix
            backend:
              service:
                name: edge-service
                port:
                  number: 9000
```

### 9.5.2 配置 TLS

```yaml
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: polar-bookshop-ingress-tls
spec:
  tls:
    - hosts:
        - polar-bookshop.local
      secretName: polar-bookshop-tls
  rules:
    - host: polar-bookshop.local
      http:
        paths:
          - path: /
            pathType: Prefix
            backend:
              service:
                name: edge-service
                port:
                  number: 9000
```

通过 Ingress，您可以统一管理外部访问，配置 SSL/TLS 终止，以及基于主机名或路径路由流量。
