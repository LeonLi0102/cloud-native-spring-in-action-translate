## 9.3 使用 Spring Cloud Gateway 和 Redis 实现请求限流

限流是一种控制应用程序资源使用的技术，可以防止系统过载并确保公平使用。

### 9.3.1 理解限流

限流可以基于多种因素：

* **每秒请求数（RPS）** — 限制每秒处理的请求数
* **并发请求数** — 限制同时处理的请求数
* **基于用户** — 不同用户有不同的限制
* **基于 IP** — 基于客户端 IP 地址限制

### 9.3.2 配置 Redis 限流

Spring Cloud Gateway 提供了 RequestRateLimiter 过滤器，使用 Redis 作为后端存储：

```yaml
spring:
  cloud:
    gateway:
      routes:
        - id: catalog-route
          uri: http://localhost:9001
          predicates:
            - Path=/books/**
          filters:
            - name: RequestRateLimiter
              args:
                redis-rate-limiter.replenishRate: 10
                redis-rate-limiter.burstCapacity: 20
                key-resolver: "#{@userKeyResolver}"
```

### 9.3.3 自定义限流键

```java
@Configuration
public class RateLimitConfig {
    
    @Bean
    public KeyResolver userKeyResolver() {
        return exchange -> Mono.just(
            exchange.getRequest().getPath().toString()
        );
    }
}
```
