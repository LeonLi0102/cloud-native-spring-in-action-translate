## 9.4 使用 Redis 进行分布式会话管理

在微服务架构中，会话管理是一个挑战。当请求被路由到不同的服务实例时，会话数据需要在所有实例之间共享。

### 9.4.1 配置 Spring Session

Spring Session 提供了管理用户会话信息的 API 和实现。它可以将会话存储在 Redis、数据库或其他存储中。

添加依赖：

```groovy
dependencies {
    implementation 'org.springframework.session:spring-session-data-redis'
    implementation 'org.springframework.boot:spring-boot-starter-data-redis'
}
```

配置 Redis 会话：

```yaml
spring:
  session:
    store-type: redis
    timeout: 30m
  redis:
    host: localhost
    port: 6379
```

### 9.4.2 在 Edge Service 中使用分布式会话

```java
@Configuration
@EnableRedisHttpSession(maxInactiveIntervalInSeconds = 1800)
public class SessionConfig {
}
```

这样，无论请求被路由到哪个服务实例，会话数据都可以从 Redis 中获取。
