### 7.1.1 使用本地 Kubernetes 集群

在第 2 章中，我们使用了 minikube（https://minikube.sigs.k8s.io），一个在本地环境运行 Kubernetes 集群的工具。我们使用 minikube CLI 基于默认配置创建了本地 Kubernetes 集群。在本节中，您将看到如何为 minikube 定义自定义配置，以便在初始化新的本地 Kubernetes 集群以部署 Polar Bookshop 时使用。

> 注意：如果尚未安装 minikube，请参阅附录 A 中的 A.3 节说明。

由于我们在 Docker 上运行 minikube，请记住先启动 Docker Engine。然后通过执行 minikube stop 命令确保默认集群未运行。

让我们在 Docker 上创建一个名为 polar 的新 Kubernetes 集群。这次，我们还想声明 CPU 和内存的资源限制：

```bash
$ minikube start --cpus 2 --memory 4g --driver docker --profile polar
```

您可以使用以下命令获取集群中所有节点的列表：

```bash
$ kubectl get nodes

NAME     STATUS   ROLES                  AGE   VERSION
polar    Ready    control-plane,master   21s   v1.24.3
```

您还可以使用 kubectl 配置和管理多个集群上下文：

```bash
$ kubectl config get-contexts
$ kubectl config current-context
$ kubectl config use-context polar
```

在本章的剩余部分，我将假设您拥有这个本地集群并正在运行。您可以随时使用 minikube stop --profile polar 停止集群，并使用 minikube start --profile polar 重新启动。
