### 7.1.2 在本地集群中管理数据服务

在第 5 章中，您了解到数据服务是有状态的组件，在云环境中由于处理存储的挑战需要特别关注。在 Kubernetes 中管理持久化和存储是一个复杂的话题，通常不是开发人员的职责。

当您在生产环境中部署 Polar Bookshop 系统时，您将依赖云提供商提供的托管数据服务，因此我已为您准备了在本地 Kubernetes 集群中部署 PostgreSQL 的配置。请查看本书附带的源代码仓库（Chapter07/07-end），并将 polar-deployment/kubernetes/platform/development 文件夹的内容复制到您的 polar-deployment 仓库中。

打开终端窗口，导航到 polar-deployment 仓库中的 kubernetes/platform/development 文件夹，运行以下命令在本地集群中部署 PostgreSQL：

```bash
$ kubectl apply -f services
```

结果将是在本地 Kubernetes 集群中运行 PostgreSQL 容器的 Pod。您可以使用以下命令检查：

```bash
$ kubectl get pod

NAME                              READY   STATUS    RESTARTS   AGE
polar-postgres-677b76bfc5-lkkqn   1/1     Running   0          48s
```

> 提示：您可以通过运行 kubectl logs deployment/polar-postgres 来检查数据库日志。
