## 7.4 将 Polar Bookshop 部署到 Kubernetes

在本节中，我们将把 Polar Bookshop 系统的所有组件部署到本地 Kubernetes 集群。

### 7.4.1 部署所有服务

使用 Docker Compose 文件生成 Kubernetes 清单，或者手动创建 Deployment 和 Service 清单。

部署顺序：

1. **Config Server** — 配置服务必须先运行，因为其他服务依赖它
2. **PostgreSQL** — 数据库服务
3. **Catalog Service** — 图书目录服务
4. **其他微服务** — 根据依赖关系依次部署

使用 kubectl 部署所有服务：

```bash
$ kubectl apply -f kubernetes/
```

查看所有部署的 Pod：

```bash
$ kubectl get pods -w
```

查看所有服务：

```bash
$ kubectl get services
```

### 7.4.2 验证部署

检查所有 Pod 是否正在运行：

```bash
$ kubectl get pods

NAME                                    READY   STATUS    RESTARTS   AGE
catalog-service-6d4b8c7f9d-xxxxx       1/1     Running   0          2m
config-server-5f7b8c9d6e-xxxxx         1/1     Running   0          3m
polar-postgres-677b76bfc5-lkkqn        1/1     Running   0          5m
```

测试服务端点：

```bash
$ minikube service catalog-service --url
http://192.168.49.2:30001

$ curl http://192.168.49.2:30001/books
```

### 7.4.3 扩展服务

Kubernetes 可以轻松扩展服务的副本数：

```bash
$ kubectl scale deployment catalog-service --replicas=3
```

查看扩展后的 Pod：

```bash
$ kubectl get pods -l app=catalog-service

NAME                                    READY   STATUS    RESTARTS   AGE
catalog-service-6d4b8c7f9d-xxxxx       1/1     Running   0          5m
catalog-service-6d4b8c7f9d-yyyyy       1/1     Running   0          10s
catalog-service-6d4b8c7f9d-zzzzz       1/1     Running   0          10s
```

### 7.4.4 更新服务

进行滚动更新：

```bash
$ kubectl set image deployment/catalog-service catalog-service=ghcr.io/your-username/catalog-service:new-version
```

查看更新状态：

```bash
$ kubectl rollout status deployment/catalog-service
```

如果更新有问题，回滚：

```bash
$ kubectl rollout undo deployment/catalog-service
```

### 7.4.5 清理资源

删除所有部署的资源：

```bash
$ kubectl delete -f kubernetes/
```

或删除整个命名空间：

```bash
$ kubectl delete namespace polar
```
