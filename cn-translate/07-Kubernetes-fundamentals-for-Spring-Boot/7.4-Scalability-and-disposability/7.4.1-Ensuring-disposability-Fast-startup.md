### 7.4.1 确保可弃置性：快速启动

传统部署在应用程序服务器上的应用程序启动需要相当长的时间。它们在准备好接受连接之前花费几分钟的时间并不罕见。另一方面，云原生应用程序应该针对快速启动进行优化，在几秒钟而不是几分钟内变得就绪。Spring Boot 已经针对快速启动进行了优化，每个新版本都附带了更多改进。

快速启动在云环境中是相关的，因为应用程序是可弃置的，并且会被频繁创建、销毁和扩展。启动越快，新的应用程序实例就越早准备好接受连接。

标准应用程序（如微服务）在几秒钟范围内的启动时间表现良好。另一方面，无服务器应用程序通常需要更快的启动阶段，在毫秒而非秒的范围内。Spring Boot 同时满足这两种需求，但第二种用例可能需要一些额外的配置。

在第 16 章中，您将了解使用 Spring Cloud Function 的无服务器应用程序，我将向您展示如何使用 Spring Native 和 GraalVM 将它们打包为原生镜像。结果将是一个几乎即时启动的应用程序，资源消耗降低，镜像大小减小。
