## 7.6 部署流水线：验证 Kubernetes 清单

第 3 章介绍了部署流水线的概念及其在持续交付方法中快速、可靠、安全交付软件的重要性。到目前为止，我们已经自动化了部署流水线的第一部分：提交阶段。在开发者将新代码提交到主线后，该阶段经过构建、单元测试、集成测试、静态代码分析和打包。在此阶段结束时，一个可执行的应用程序构件被发布到构件仓库中。这是一个发布候选版本。

在本章中，您学习了如何使用基于资源清单的声明式方法在 Kubernetes 上部署 Spring Boot 应用程序。这些清单对于在 Kubernetes 上成功部署发布候选版本至关重要，因此我们应该保证它们的正确性。本节将向您展示如何将 Kubernetes 清单验证作为提交阶段的一部分。
