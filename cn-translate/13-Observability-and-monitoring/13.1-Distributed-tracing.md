## 13.1 分布式追踪

分布式追踪是跟踪请求在分布式系统中传播路径的技术，帮助您理解服务之间的调用关系和性能瓶颈。

### 13.1.1 理解分布式追踪

分布式追踪的核心概念：

* **Span** — 一个工作单元，包含操作名称、开始时间和持续时间
* **Trace** — 一组 Span，表示一个完整的请求路径
* **Context Propagation** — 在服务之间传递追踪上下文

### 13.1.2 使用 Micrometer Tracing

```xml
<dependency>
    <groupId>io.micrometer</groupId>
    <artifactId>micrometer-tracing-bridge-brave</artifactId>
</dependency>
<dependency>
    <groupId>io.zipkin.reporter2</groupId>
    <artifactId>zipkin-reporter-brave</artifactId>
</dependency>
```

### 13.1.3 配置 Zipkin

```yaml
management:
  tracing:
    sampling:
      probability: 1.0
  zipkin:
    tracing:
      endpoint: http://localhost:9411/api/v2/spans
```

### 13.1.4 自定义 Span

```java
@Service
public class BookService {
    
    private final Tracer tracer;
    
    public Book getBook(String isbn) {
        Span span = tracer.nextSpan().name("getBook").start();
        try (Tracer.SpanInScope ws = tracer.withSpan(span)) {
            return bookRepository.findByIsbn(isbn);
        } finally {
            span.end();
        }
    }
}
```

分布式追踪帮助您可视化请求在微服务架构中的流动。
