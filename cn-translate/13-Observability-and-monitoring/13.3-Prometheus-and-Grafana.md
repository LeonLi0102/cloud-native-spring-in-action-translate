## 13.3 Prometheus 和 Grafana

Prometheus 是一个开源的监控和告警系统，Grafana 是一个可视化和分析平台。它们经常一起使用来监控云原生应用程序。

### 13.3.1 配置 Prometheus

```yaml
# prometheus.yml
global:
  scrape_interval: 15s

scrape_configs:
  - job_name: 'spring-boot'
    metrics_path: '/actuator/prometheus'
    static_configs:
      - targets: ['localhost:9001']
```

### 13.3.2 配置 Grafana

1. 添加 Prometheus 数据源
2. 导入 Spring Boot 仪表板（ID: 12900）
3. 自定义图表和告警

### 13.3.3 Docker Compose 配置

```yaml
version: '3.8'

services:
  prometheus:
    image: prom/prometheus
    ports:
      - "9090:9090"
    volumes:
      - ./prometheus.yml:/etc/prometheus/prometheus.yml
  
  grafana:
    image: grafana/grafana
    ports:
      - "3000:3000"
    environment:
      - GF_SECURITY_ADMIN_PASSWORD=admin
  
  catalog-service:
    build: .
    ports:
      - "9001:9001"
```

### 13.3.4 创建告警规则

```yaml
# alert_rules.yml
groups:
  - name: spring-boot-alerts
    rules:
      - alert: HighErrorRate
        expr: rate(http_server_requests_seconds_count{status=~"5.."}[5m]) > 0.1
        for: 5m
        labels:
          severity: critical
        annotations:
          summary: "High error rate detected"
          description: "Error rate is above 10% for 5 minutes"
```

Prometheus 和 Grafana 提供了强大的监控和可视化能力。
