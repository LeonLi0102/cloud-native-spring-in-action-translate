## 12.3 审计日志

审计日志是跟踪系统中重要事件的过程，对于安全合规和问题排查非常重要。

### 12.3.1 实现审计日志

```java
@Component
public class AuditLogger {
    
    private static final Logger auditLog = 
        LoggerFactory.getLogger("AUDIT");
    
    @EventListener
    public void handleAuthenticationSuccess(AuthenticationSuccessEvent event) {
        auditLog.info("User '{}' authenticated successfully from IP '{}'",
            event.getAuthentication().getName(),
            getCurrentIP());
    }
    
    @EventListener
    public void handleAuthenticationFailure(AuthenticationFailureEvent event) {
        auditLog.warn("Authentication failed for user '{}' from IP '{}': {}",
            event.getAuthentication().getName(),
            getCurrentIP(),
            event.getException().getMessage());
    }
    
    private String getCurrentIP() {
        // 获取客户端IP地址
        return "N/A";
    }
}
```

### 12.3.2 使用 Spring Data 审计

```java
@Entity
@EntityListeners(AuditingEntityListener.class)
public class Book {
    @Id
    private Long id;
    
    @CreatedDate
    private Instant createdDate;
    
    @LastModifiedDate
    private Instant lastModifiedDate;
    
    @CreatedBy
    private String createdBy;
    
    @LastModifiedBy
    private String lastModifiedBy;
}
```

### 12.3.3 启用审计

```java
@Configuration
@EnableJpaAuditing
public class AuditConfig {
}
```

审计日志可以帮助您追踪谁在什么时候做了什么，对于安全审计和故障排查非常有价值。
