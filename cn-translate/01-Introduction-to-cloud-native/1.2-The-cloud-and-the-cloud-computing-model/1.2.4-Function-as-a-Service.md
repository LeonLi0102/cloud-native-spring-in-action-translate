### 1.2.4 函数即服务（FaaS）

函数即服务（Function as a Service，FaaS）是 Serverless 计算的核心。使用 FaaS，你只需要编写单个函数或小段代码，云平台会负责处理其余的一切：服务器、扩展、负载均衡，甚至在没有请求时将实例缩减到零。

**FaaS 的特点：**

* 你负责编写函数逻辑
* 云提供商管理服务器、扩展和运行时
* 按函数调用次数和执行时间付费
* 自动扩展到零（不使用时不收费）

**常见的 FaaS 提供商：**

* AWS Lambda
* Azure Functions
* Google Cloud Functions
* OpenFaaS（开源）

**适用场景：**

* 事件驱动架构
* 微服务中的单个功能
* 数据处理管道
* API 后端

**示例：** 编写一个 AWS Lambda 函数，当 S3 存储桶中有新文件上传时触发，处理文件并存储结果。你只需要编写处理函数的代码，AWS 负责管理服务器和扩展。
