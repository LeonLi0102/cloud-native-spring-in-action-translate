### 1.2.2 容器即服务（CaaS）

容器即服务（Container as a Service，CaaS）是介于 IaaS 和 PaaS 之间的服务模型。它提供了一个用于运行和管理容器化应用程序的平台。使用 CaaS，你不需要管理底层的虚拟机和操作系统，但对容器及其编排拥有更多控制权。

**CaaS 的特点：**

* 你负责管理容器、容器编排和应用程序
* 云提供商管理虚拟机、操作系统和容器运行时
* 提供容器编排能力（如 Kubernetes）
* 按容器实例和资源使用量付费

**常见的 CaaS 提供商：**

* Amazon Elastic Kubernetes Service（EKS）
* Azure Kubernetes Service（AKS）
* Google Kubernetes Engine（GKE）
* Red Hat OpenShift

**适用场景：**

* 微服务架构
* 需要容器编排和管理
* 需要自动扩展和负载均衡
* 希望简化容器化应用程序的部署

**示例：** 在 GKE 上部署一个 Kubernetes 集群，运行多个 Spring Boot 微服务容器。你不需要管理底层的虚拟机，但需要编写 Kubernetes 清单文件来定义 Pod、Deployment 和 Service。
