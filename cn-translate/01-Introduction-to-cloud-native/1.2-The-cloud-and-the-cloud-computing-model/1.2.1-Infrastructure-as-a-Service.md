### 1.2.1 基础设施即服务（IaaS）

基础设施即服务（Infrastructure as a Service，IaaS）是云计算的基础层。它提供对基本计算资源的访问：虚拟机、存储和网络。使用 IaaS，你可以租用而不是拥有物理硬件。你对操作系统和应用程序拥有完全的控制权，但需要自己管理底层基础设施。

**IaaS 的特点：**

* 你负责管理操作系统、中间件和应用程序
* 云提供商管理物理硬件、网络和虚拟化
* 按使用量付费
* 可以根据需要快速扩展或收缩

**常见的 IaaS 提供商：**

* Amazon Web Services（EC2、EBS、VPC）
* Microsoft Azure（虚拟机、磁盘、虚拟网络）
* Google Cloud Platform（Compute Engine、Persistent Disk、VPC）

**适用场景：**

* 需要完全控制基础设施
* 有特殊的操作系统或软件要求
* 需要运行传统应用程序
* 需要自定义网络配置

**示例：** 在 AWS EC2 上启动一个 Ubuntu 虚拟机，安装 Java 和 Spring Boot，部署你的应用程序。你完全控制操作系统和应用栈，但也需要自己处理安全补丁、备份和扩展。
