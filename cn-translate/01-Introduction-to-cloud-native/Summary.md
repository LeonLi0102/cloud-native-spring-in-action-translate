# 第 1 章 小结

在本章中，我们学习了：

* **云原生的定义**——云原生应用程序是专门为云设计的，具有可扩展性、松散耦合、弹性、可管理和可观测性等特性。
* **云计算模型**——包括 IaaS、CaaS、PaaS、FaaS 和 SaaS 五种服务模型，每种模型提供不同程度的抽象和控制。
* **云原生的 3 个 P**——平台（Platforms）、特性（Properties）和实践（Practices）。
* **云原生的五大特性**——可扩展性、松散耦合、弹性、可观测性和可管理性。
* **支持云原生的三大实践**——自动化、持续交付和 DevOps。
* **何时选择云原生**——根据速度、弹性、规模和成本等因素评估。
* **云原生拓扑**——容器、编排（Kubernetes）和 Serverless。
* **云原生架构**——从单体到微服务的演进，以及基于服务的架构设计。

在下一章中，我们将深入探讨云原生开发的模式和技术，包括十二要素应用方法论和 Spring 生态系统。
