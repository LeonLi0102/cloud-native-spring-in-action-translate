### 4.4.1 设置配置客户端

将 Spring Boot 应用程序与配置服务器集成的第一件事是添加 Spring Cloud Config Client 的新依赖。更新 Catalog Service 项目（`catalog-service`）的 `build.gradle` 文件如下。添加后记得刷新或重新导入 Gradle 依赖。

**代码清单 4.14 添加 Spring Cloud Config Client 依赖**

```groovy
ext {
 set('springCloudVersion', "2021.0.3")
}

dependencies {
 ...
 implementation 'org.springframework.cloud:spring-cloud-starter-config'
}

dependencyManagement {
 imports {
 mavenBom "org.springframework.cloud:
 spring-cloud-dependencies:${springCloudVersion}"
 }
}
```

现在我们需要指示 Catalog Service 从 Config Service 获取配置。您可以通过 `spring.config.import` 属性传入 `configserver:` 作为属性值来实现。当您在本地环境中处理 Catalog Service 等客户端应用程序时，可能不希望配置服务器运行，在这种情况下，您可以使用 `optional:` 前缀使其变为可选（`optional:configserver:`）。如果启动 Catalog Service 时配置服务器未运行，应用程序将记录一条警告，但不会停止工作。请注意不要在生产环境中将其设为可选，否则您可能会使用错误的配置。

接下来，Catalog Service 需要知道联系 Config Service 的 URL。您有两个选择。可以将它添加到 `spring.config.import` 属性中（`optional:configserver:http://localhost:8888`），或依赖更具体的 `spring.cloud.config.uri` 属性。我们将使用第二个选项，这样在不同环境中部署应用程序时只需更改 URL 值。

由于配置服务器使用应用程序名称返回正确的配置数据，您还需要将 `spring.application.name` 属性设置为 `catalog-service`。还记得 `{application}` 参数吗？这就是使用 `spring.application.name` 值的地方。

打开 Catalog Service 项目的 `application.yml` 文件并应用以下配置。

**代码清单 4.15 指示 Catalog Service 从 Config Service 获取配置**

```yaml
spring:
 application:
 name: catalog-service # 应用程序名称，配置服务器用于过滤配置
 config:
 import: "optional:configserver:" # 当可用时从配置服务器导入配置数据
 cloud:
 config:
 uri: http://localhost:8888 # 配置服务器的 URL
```

让我们验证它是否正常工作。Catalog Service 应用程序包含一个 `polar.greeting` 属性，值为 "Welcome to the local book catalog!"。当使用配置服务器时，集中式属性优先于本地属性，因此将使用您在 `config-repo` 仓库中定义的值。

首先，运行 Config Service（`./gradlew bootRun`）。然后将 Catalog Service 打包为 JAR 工件（`./gradlew bootJar`）并按如下方式运行：

```bash
$ java -jar build/libs/catalog-service-0.0.1-SNAPSHOT.jar
```

然后，在另一个终端窗口中，向根端点发送 GET 请求：

```bash
$ http :9001/
Welcome to the catalog from the config server!
```

如预期，应用程序返回的欢迎消息是 `config-repo` 仓库中定义的，具体在 `catalog-service.yml` 文件中。

您还可以尝试启用 `prod` profile 运行应用程序。使用 Ctrl-C 停止 Catalog Service，然后以 `prod` 作为活动 profile 重新启动应用程序：

```bash
$ java -jar build/libs/catalog-service-0.0.1-SNAPSHOT.jar \
 --spring.profiles.active=prod
```

现在预期结果是 `config-repo` 仓库中 `catalog-service-prod.yml` 文件中定义的消息：

```bash
$ http :9001/
Welcome to the production catalog from the config server
```

再次使用 Ctrl-C 停止之前的应用程序执行。
