### 4.3.4 理解 Config Server 的 REST API

Config Server 暴露了几个 REST 端点来获取配置数据：

#### 主要端点

| 端点 | 描述 |
|------|------|
| `/{application}/{profile}` | 获取指定应用和环境的配置 |
| `/{application}-{profile}.properties` | 获取属性文件格式的配置 |
| `/{application}-{profile}.yml` | 获取 YAML 格式的配置 |

#### 示例

```bash
# 获取 catalog-service 在 development 环境的配置
$ http :8888/catalog-service/development
{
    "name": "catalog-service",
    "profiles": ["development"],
    "label": "main",
    "version": "abc123",
    "propertySources": [...]
}

# 获取 YAML 格式的配置
$ http :8888/catalog-service/development.yml
spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/polardb_catalog
```

#### 安全考虑

Config Server 应该配置访问控制，只允许授权的客户端访问配置数据：

```yaml
spring:
  security:
    user:
      name: configuser
      password: configpass
```

客户端访问时需要提供凭据：

```yaml
spring:
  cloud:
    config:
      uri: http://configuser:configpass@localhost:8888
```
