### 4.3.3 使 Config Server 更有韧性

Config Server 可能成为单点故障。为了提高可用性，可以：

#### 1. 运行多个 Config Server 实例

```yaml
# 使用 Kubernetes 部署多个副本
apiVersion: apps/v1
kind: Deployment
metadata:
  name: config-server
spec:
  replicas: 3
  selector:
    matchLabels:
      app: config-server
  template:
    metadata:
      labels:
        app: config-server
    spec:
      containers:
        - name: config-server
          image: config-server:latest
          ports:
            - containerPort: 8888
```

#### 2. 启用本地缓存

```yaml
spring:
  cloud:
    config:
      server:
        git:
          uri: https://github.com/your-username/config-repo
          clone-on-start: true
        fail-on-access-error: false
```

#### 3. 配置健康检查

```yaml
management:
  endpoint:
    health:
      show-details: always
  endpoints:
    web:
      exposure:
        include: health,info,refresh
```

#### 4. 使用 Spring Cloud Config 的故障转移

```yaml
spring:
  cloud:
    config:
      server:
        git:
          uri: https://github.com/your-username/config-repo
          backupUri: file:///backup/config-repo
```
