### 4.3.1 使用 Git 存储配置数据

Git 是 Spring Cloud Config 最常用的后端存储。它提供了配置数据的版本控制，可以跟踪更改并回滚到以前的版本。

配置 Config Server 使用 Git 仓库：

```yaml
# application.yml
server:
  port: 8888

spring:
  cloud:
    config:
      server:
        git:
          uri: https://github.com/your-username/config-repo
          default-label: main
          clone-on-start: true
          search-paths:
            - '{application}'
```

Git 存储的优势：
* 版本控制 — 可以跟踪配置更改的历史
* 分支支持 — 不同环境可以使用不同的分支
* 回滚能力 — 可以轻松回滚到以前的配置版本
* 审计跟踪 — 可以查看谁在什么时候修改了配置

配置仓库结构示例：
```
config-repo/
├── catalog-service/
│   ├── application.yml
│   ├── application-development.yml
│   └── application-production.yml
└── order-service/
    ├── application.yml
    ├── application-development.yml
    └── application-production.yml
```
