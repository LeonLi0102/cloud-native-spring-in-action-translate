## 2.1 云原生开发原则：十二要素及更多

Heroku 云平台的工程师们提出了十二要素（12-Factor）方法论，作为设计和构建云原生应用程序的开发原则集合。他们将多年的经验提炼为构建 Web 应用程序的最佳实践，这些应用具有以下特征：

* 适合部署在云平台上
* 设计上可扩展
* 可跨系统移植
* 支持持续部署和敏捷开发

目标是帮助开发者构建适合云的应用程序，强调实现最佳结果需要考虑的重要因素。

后来，Kevin Hoffman 在他的《Beyond the Twelve-Factor App》一书中修订和扩展了这个方法论，更新了原有要素的内容，并增加了三个额外的要素。从现在起，我将这个扩展的原则集称为**十五要素方法论**。

这 15 个要素将贯穿本书，因为它们是开发云原生应用程序的良好起点。无论你是从头构建新应用程序，还是将传统系统迁移到云，这些原则都能为你提供指导。我将在相关章节详细阐述它们，并演示如何应用到 Spring 应用程序中。

让我们逐一介绍这些要素。
