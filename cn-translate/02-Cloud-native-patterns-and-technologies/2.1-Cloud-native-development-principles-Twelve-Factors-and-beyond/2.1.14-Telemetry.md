### 2.1.14 遥测

可观测性是云原生应用的特性之一。在云中管理分布式系统是复杂的，管理这种复杂性的唯一方法是确保每个系统组件提供正确的数据来远程监控系统行为。遥测数据的例子包括日志、指标、追踪、健康状态和事件。Hoffman 使用了一个非常形象的比喻来强调遥测的重要性：将你的应用视为太空探测器。你需要什么样的遥测数据来远程监控和控制你的应用？

**遥测三大支柱：**

* **日志（Logs）**——记录事件，用于调试和审计
* **指标（Metrics）**——数值数据，用于监控系统健康和性能
* **追踪（Traces）**——请求路径，用于分析分布式系统中的问题

**Spring Boot 遥测配置：**

```yaml
# Actuator 端点
management:
 endpoints:
 web:
 exposure:
 include: health,info,metrics,prometheus
 metrics:
 export:
 prometheus:
 enabled: true
 distribution:
 percentiles-histogram:
 http.server.requests: true

# 配置日志
logging:
 level:
 root: INFO
 com.polarbookshop: DEBUG
```

**Micrometer 指标示例：**

```java
@RestController
public class CatalogController {
 
 private final MeterRegistry registry;
 
 @GetMapping("/api/catalog")
 public List<Book> getAllBooks() {
 Timer.Sample sample = Timer.start(registry);
 try {
 List<Book> books = catalogService.findAll();
 sample.stop(Timer.builder("catalog.get.all")
 .tag("status", "success")
 .register(registry));
 return books;
 } catch (Exception e) {
 sample.stop(Timer.builder("catalog.get.all")
 .tag("status", "failed")
 .register(registry));
 throw e;
 }
 }
}
```

**OpenTelemetry 分布式追踪：**

```yaml
# 配置 OpenTelemetry
management:
 tracing:
 sampling:
 probability: 1.0 # 采样率 100%
```

```java
// 自动追踪 HTTP 请求和数据库调用
// 无需额外配置
@RestController
public class OrderController {
 
 @GetMapping("/orders/{id}")
 public Order getOrder(@PathVariable Long id) {
 // 自动追踪
 return orderService.findById(id);
 }
}
```
