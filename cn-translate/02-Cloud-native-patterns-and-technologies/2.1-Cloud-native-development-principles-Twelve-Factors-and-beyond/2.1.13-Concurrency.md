### 2.1.13 并发

创建无状态应用不足以确保可扩展性。如果需要扩展，意味着需要服务更多用户。因此，你的应用应该允许并发处理，以便同时服务多个用户。

十五要素方法论将进程定义为一等公民。这些进程应该是水平可扩展的，将工作负载分配到不同机器上的多个进程中，只有在应用是无状态的情况下，这种并发处理才成为可能。在 JVM 应用中，我们通过线程池中的多个线程来处理并发。

进程可以根据其类型进行分类。例如，你可能有处理 HTTP 请求的 Web 进程和在后台执行计划作业的工作者进程。

**并发处理模式：**

```java
// Spring Boot 异步处理
@Service
public class OrderService {
 
 @Async
 public CompletableFuture<Order> processOrderAsync(Order order) {
 // 异步处理订单
 Order processed = processOrder(order);
 return CompletableFuture.completedFuture(processed);
 }
}

// 响应式编程（WebFlux）
@RestController
public class OrderController {
 
 @GetMapping("/orders/{id}")
 public Mono<Order> getOrder(@PathVariable Long id) {
 // 非阻塞处理
 return orderService.findById(id);
 }
}
```

**水平扩展配置：**

```yaml
# Kubernetes 水平扩展
apiVersion: autoscaling/v2
kind: HorizontalPodAutoscaler
metadata:
 name: catalog-service-hpa
spec:
 scaleTargetRef:
 apiVersion: apps/v1
 kind: Deployment
 name: catalog-service
 minReplicas: 2
 maxReplicas: 20
 metrics:
 - type: Resource
 resource:
 name: cpu
 target:
 type: Utilization
 averageUtilization: 70
```

**线程池配置：**

```yaml
# Spring Boot 线程池配置
spring:
 task:
 execution:
 pool:
 core-size: 10
 max-size: 50
 queue-capacity: 100
```
