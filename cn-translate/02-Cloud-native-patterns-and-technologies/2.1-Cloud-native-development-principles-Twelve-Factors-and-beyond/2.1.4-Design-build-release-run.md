### 2.1.4 设计、构建、发布、运行

代码库在其从设计到部署到生产的过程中经历不同的阶段：

* **设计阶段**——确定特定应用功能所需的技术、依赖和工具。
* **构建阶段**——代码库与其依赖一起编译和打包，形成一个不可变的制品，称为构建。构建制品必须具有唯一标识。
* **发布阶段**——构建与特定的部署配置结合。每个发布都是不可变的，应该具有唯一可识别性，例如使用语义版本号（例如 3.9.4）或时间戳（例如 2022-07-07_17:21）。发布应该存储在中央仓库中以便访问，例如需要回滚到以前版本时。
* **运行阶段**——应用从特定发布在执行环境中运行。

十五要素方法论要求严格分离这些阶段，不允许在运行时更改代码，因为这会导致与构建阶段的不匹配。构建和发布制品应该是不可变的，并用唯一标识符标记，以保证可重复性。

**发布版本示例：**

```
# 语义版本号
v1.0.0
v1.0.1
v1.1.0
v2.0.0

# 时间戳版本
2022-07-07_17:21
2022-07-07_18:30

# Git commit hash
abc1234
def5678
```

**不可变制品的好处：**

* 可以随时回滚到任何版本
* 确保开发、测试、生产环境使用相同的制品
* 便于追踪和审计
