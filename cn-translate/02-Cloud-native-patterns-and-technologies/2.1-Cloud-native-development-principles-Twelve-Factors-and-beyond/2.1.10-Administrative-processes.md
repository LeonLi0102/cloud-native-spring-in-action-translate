### 2.1.10 管理进程

一些管理任务通常需要来支持应用。数据库迁移、批处理作业或维护作业等任务应该被视为一次性进程。就像应用进程一样，管理任务的代码应该在版本控制中跟踪，与其支持的应用一起交付，并在与应用相同的环境中执行。

通常，将管理任务构建成小型独立服务是一个好主意，这些服务运行一次后就被丢弃，或者构建成在无状态平台上配置的函数，当特定事件发生时被触发。你也可以将它们嵌入应用本身，通过调用特定端点来激活。

**管理任务类型：**

* **数据库迁移**——使用 Flyway 或 Liquibase 管理数据库 schema 变更
* **批处理作业**——定期执行的数据处理任务
* **维护任务**——数据清理、缓存刷新等

**Flyway 数据库迁移示例：**

```sql
-- V1__create_books_table.sql
CREATE TABLE books (
 id BIGSERIAL PRIMARY KEY,
 title VARCHAR(255) NOT NULL,
 author VARCHAR(255) NOT NULL,
 price DECIMAL(10, 2) NOT NULL,
 created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- V2__add_isbn_column.sql
ALTER TABLE books ADD COLUMN isbn VARCHAR(13);
```

**Spring Boot 管理端点：**

```yaml
# 通过 Actuator 端点执行管理任务
management:
 endpoints:
 web:
 exposure:
 include: health,info,metrics,env,beans
 endpoint:
 health:
 show-details: when-authorized
```
