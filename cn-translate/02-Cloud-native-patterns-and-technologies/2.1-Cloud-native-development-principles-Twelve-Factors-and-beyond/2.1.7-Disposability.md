### 2.1.7 易处理

在传统环境中，你需要精心呵护应用，确保它们持续运行永不终止。在云环境中，你不需要这么担心：应用是临时的。如果发生故障且应用不再响应，你可以终止它并启动新实例。如果有高负载峰值，可以启动更多应用实例来应对增加的工作负载。我们说一个应用是易处理的，如果它可以随时启动或停止。

为了以这种方式动态处理应用实例，你应该设计它们在需要新实例时快速启动，在不需要时优雅关闭。快速启动使系统具有弹性，确保健壮性和韧性。没有快速启动，你将遇到性能和可用性问题。

优雅关闭是指应用在收到终止信号后，停止接受新请求，完成正在进行的请求，然后退出。对于 Web 进程来说，这很简单。对于其他情况，如工作者进程，它们负责的工作必须返回到工作队列，然后才能退出。

**Spring Boot 优雅关闭配置：**

```yaml
server:
 shutdown: graceful

spring:
 lifecycle:
 timeout-per-shutdown-phase: 30s

# Kubernetes 中的优雅关闭
apiVersion: apps/v1
kind: Deployment
spec:
 template:
 spec:
 terminationGracePeriodSeconds: 60
```

**快速启动的重要性：**

* **弹性扩展**——快速启动使系统能够快速应对负载变化
* **故障恢复**——快速重启减少停机时间
* **零停机部署**——快速启动新实例，优雅关闭旧实例

**优雅关闭的实现：**

```java
@Component
public class GracefulShutdown implements DisposableBean {
 
 @Override
 public void destroy() {
 // 清理资源
 // 完成正在处理的请求
 // 关闭数据库连接
 log.info("Application shutting down gracefully...");
 }
}
```
