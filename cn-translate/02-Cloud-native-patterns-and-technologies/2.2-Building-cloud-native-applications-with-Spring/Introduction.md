## 2.2 使用 Spring 构建云原生应用

现在是时候更具体地开始讨论技术了。到目前为止，你已经了解了云原生方法和我们将遵循的主要开发实践。现在让我们来看看 Spring。如果你正在阅读这本书，你可能已经有一些 Spring 的使用经验，并且想学习如何使用它来构建云原生应用。

Spring 生态系统提供了处理应用可能面临的几乎任何需求的功能，包括云原生应用的需求。Spring 是迄今为止使用最广泛的 Java 框架。它已经存在多年，稳定可靠。Spring 背后的社区非常出色，愿意推动它不断前进和改进。技术和开发实践在不断演进，Spring 非常善于跟上它们。因此，使用 Spring 进行下一个云原生项目是一个极好的选择。

本节将重点介绍 Spring 生态系统的一些有趣特性。然后我们将开始创建一个 Spring Boot 应用。
