### 2.2.1 Spring 生态系统概览

Spring 包含多个项目，涵盖软件开发的许多不同方面：Web 应用、安全、数据访问、集成、批处理、配置、消息、大数据等等。Spring 平台的美妙之处在于它是模块化的，所以你可以只使用和组合你需要的项目。无论你需要构建什么类型的应用，Spring 都可能帮到你。

**Spring 核心项目：**

| 项目 | 用途 |
|------|------|
| Spring Framework | 核心框架，提供依赖注入、AOP 等 |
| Spring Boot | 快速构建独立、生产级应用 |
| Spring Cloud | 分布式系统工具（配置、服务发现等） |
| Spring Data | 简化数据访问（JPA、Redis、MongoDB 等） |
| Spring Security | 认证、授权、安全控制 |
| Spring Session | 分布式会话管理 |
| Spring Native | GraalVM 原生镜像支持 |

**Spring Framework** 是 Spring 平台的核心，是所有项目的起点。它支持依赖注入、事务管理、数据访问、消息传递、Web 应用等。该框架建立了企业应用的"管道"，让你可以专注于业务逻辑。

Spring Framework 提供了一个执行上下文（称为 Spring 上下文或容器），在应用的整个生命周期中管理 bean、属性和资源。

**Spring Boot** 基于框架之上，使快速构建独立的、生产就绪的应用成为可能。Spring Boot 对 Spring 和第三方库采用固执己见的观点，捆绑了合理的默认配置，让开发者只需最少的前期工作即可开始，同时仍提供完全自定义的可能性。

// Spring Boot 应用入口
@SpringBootApplication
public class CatalogServiceApplication {
 public static void main(String[] args) {
 SpringApplication.run(CatalogServiceApplication.class, args);
 }
}
