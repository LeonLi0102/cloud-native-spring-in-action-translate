## 11.2 OAuth 2.0 和 OpenID Connect

OAuth 2.0 是一个授权框架，允许第三方应用程序获得对 HTTP 服务的有限访问权限。OpenID Connect 是建立在 OAuth 2.0 之上的身份层。

### 11.2.1 OAuth 2.0 核心概念

OAuth 2.0 定义了四种授权流程：

* **授权码流程** — 最安全，适用于服务器端应用
* **隐式流程** — 适用于纯前端应用（不推荐）
* **密码流程** — 适用于高度信任的客户端
* **客户端凭证流程** — 适用于机器对机器通信

### 11.2.2 配置 OAuth 2.0 客户端

```yaml
spring:
  security:
    oauth2:
      client:
        registration:
          github:
            client-id: your-client-id
            client-secret: your-client-secret
            scope: read:user,user:email
```

### 11.2.3 OpenID Connect 配置

```yaml
spring:
  security:
    oauth2:
      client:
        registration:
          okta:
            client-id: your-client-id
            client-secret: your-client-secret
            scope: openid,profile,email
            client-name: Okta
        provider:
          okta:
            issuer-uri: https://your-domain.okta.com/oauth2/default
```

### 11.2.4 使用 Keycloak 作为身份提供者

Keycloak 是一个开源的身份和访问管理解决方案：

```yaml
spring:
  security:
    oauth2:
      client:
        registration:
          keycloak:
            client-id: spring-boot-client
            client-secret: secret
            scope: openid,profile,email
        provider:
          keycloak:
            issuer-uri: http://localhost:8080/realms/polar-bookshop
            authorization-uri: http://localhost:8080/realms/polar-bookshop/protocol/openid-connect/auth
            token-uri: http://localhost:8080/realms/polar-bookshop/protocol/openid-connect/token
            jwk-set-uri: http://localhost:8080/realms/polar-bookshop/protocol/openid-connect/certs
```

### 11.2.5 实现注销

```java
@Bean
SecurityWebFilterChain springSecurityFilterChain(ServerHttpSecurity http) {
    return http
        .authorizeExchange(exchange -> exchange
            .anyExchange().authenticated())
        .oauth2Login(Customizer.withDefaults())
        .logout(logout -> logout
            .logoutSuccessUrl("/"))
        .build();
}
```

OAuth 2.0 和 OpenID Connect 提供了标准化的身份验证和授权机制。
