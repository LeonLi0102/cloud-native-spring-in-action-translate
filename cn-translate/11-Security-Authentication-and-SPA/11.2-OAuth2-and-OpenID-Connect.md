## 11.2 OAuth 2.0 和 OpenID Connect

OAuth 2.0 是一个授权框架，允许第三方应用程序获得对 HTTP 服务的有限访问权限。OpenID Connect 是建立在 OAuth 2.0 之上的身份层。

### 11.2.1 OAuth 2.0 核心概念

OAuth 2.0 定义了四种授权流程：

* **授权码流程** — 最安全，适用于服务器端应用
* **隐式流程** — 适用于纯前端应用（不推荐）
* **密码流程** — 适用于高度信任的客户端
* **客户端凭证流程** — 适用于机器对机器通信

### 11.2.2 配置 OAuth 2.0 客户端

```yaml
spring:
  security:
    oauth2:
      client:
        registration:
          github:
            client-id: your-client-id
            client-secret: your-client-secret
            scope: read:user,user:email
```

### 11.2.3 OpenID Connect 配置

```yaml
spring:
  security:
    oauth2:
      client:
        registration:
          okta:
            client-id: your-client-id
            client-secret: your-client-secret
            scope: openid,profile,email
            client-name: Okta
        provider:
          okta:
            issuer-uri: https://your-domain.okta.com/oauth2/default
```

### 11.2.4 资源服务器配置

```java
@Configuration
@EnableResourceServer
public class ResourceServerConfig {
    
    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
        http
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/books/**").permitAll()
                .anyRequest().authenticated()
            )
            .oauth2ResourceServer(oauth2 -> oauth2
                .jwt(Customizer.withDefaults())
            );
        return http.build();
    }
}
```
