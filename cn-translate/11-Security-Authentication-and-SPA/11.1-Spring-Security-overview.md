## 11.1 Spring Security 概述

Spring Security（https://spring.io/projects/spring-security）是保护 Spring 应用程序的事实标准，支持命令式和响应式栈。它提供身份验证和授权功能，以及针对最常见攻击的保护。

### 11.1.1 理解 Spring Security 基础

Spring Security 通过过滤器提供其主要功能。当配置 Spring Security 时，框架会添加一个过滤器来拦截任何传入的 HTTP 请求。

如果用户已经过身份验证，它会将请求发送给给定的 Web 处理程序（如 @RestController 类）进行处理。如果用户未通过身份验证，它会将用户转发到登录页面并提示输入用户名和密码。

#### 添加 Spring Security 依赖

```groovy
dependencies {
    implementation 'org.springframework.boot:spring-boot-starter-security'
}
```

#### 配置安全策略

```java
@EnableWebFluxSecurity
public class SecurityConfig {
    
    @Bean
    SecurityWebFilterChain springSecurityFilterChain(ServerHttpSecurity http) {
        return http
            .authorizeExchange(exchange -> 
                exchange.anyExchange().authenticated())
            .formLogin(Customizer.withDefaults())
            .build();
    }
}
```

### 11.1.2 认证策略

Spring Security 提供了多种认证策略：

* **HTTP Basic** — 基于 HTTP 头的简单认证
* **表单登录** — 基于表单的用户界面认证
* **SAML** — 基于 SAML 的单点登录
* **OpenID Connect** — 基于 OAuth 2.0 的身份验证

### 11.1.3 授权策略

Spring Security 支持多种授权策略：

```java
@Bean
SecurityWebFilterChain springSecurityFilterChain(ServerHttpSecurity http) {
    return http
        .authorizeExchange(exchange -> exchange
            .pathMatchers("/books/**").permitAll()
            .pathMatchers("/admin/**").hasRole("ADMIN")
            .anyExchange().authenticated())
        .formLogin(Customizer.withDefaults())
        .build();
}
```

### 11.1.4 保护 REST API

```java
@Bean
SecurityWebFilterChain springSecurityFilterChain(ServerHttpSecurity http) {
    return http
        .csrf(csrf -> csrf.disable())
        .authorizeExchange(exchange -> exchange
            .pathMatchers(HttpMethod.GET, "/books/**").permitAll()
            .pathMatchers(HttpMethod.POST, "/books/**").hasRole("ADMIN")
            .anyExchange().authenticated())
        .oauth2ResourceServer(oauth2 -> oauth2
            .jwt(Customizer.withDefaults()))
        .build();
}
```

Spring Security 是保护 Spring 应用程序的强大工具，提供了全面的安全功能。
